# Docs

| Path | Role |
|------|------|
| `EPISODE_METHODOLOGY.md` | Short summary of episode definition; defers to the protocol |
| `decisions/` | Architecture Decision Records |
| `sources/` | Source discovery notes (URLs, calendars) |

Episode research is governed by `research/episodes/`:

| Path | Role |
|------|------|
| `EPISODE_PROTOCOL.md` | How to research an episode (rules, tiers, anchors, severity, dedup) |
| `episode_schema.yaml` | Machine-readable field spec — single source of truth |
| `ADMISSION_CHECKLIST.md` | One-page per-candidate gate |
| `EPISODE_LEDGER.md` | Ledger of record + generated summary |
| `RULINGS.md` | Append-only precedent log |
| `entries/*.yaml` | One file per candidate, accepted and rejected |

Governing docs live at repo root: `PROJECT_BLUEPRINT.md`, `BLUEPRINT_REVIEW.md`,
`WORKFLOW.md`, `CLAUDE.md`.
